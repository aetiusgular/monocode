# Bundled fonts

## Source Serif 4

Used by the "Serif" chat font (Settings, Appearance).

- Files: `source-serif-4-latin-wght-normal.woff2` (50,824 bytes), `source-serif-4-latin-wght-italic.woff2` (51,516 bytes). Variable weight, Latin subset.
- From the npm package `@fontsource-variable/source-serif-4` 5.2.9, which takes them from https://github.com/google/fonts (family version v14).
- SHA-256: normal `c1df4596be5029233ed2afbb8b2f6ea20784b3fb1aa5d6b5c6519ccd85eb3dfb`, italic `663e7ef3037a56dce81dfc33f68c1e6445995ffd8887991b3c0b68a7689c9da5`.
- Licence: SIL Open Font License 1.1, in `SourceSerif4-OFL.txt`, copied unchanged from the package.
- Not an npm dependency. The two files are copied in, so nothing is fetched at run time.
